ScaleShop Scalability Lab

Live workshop

An evidence-driven workshop where engineers diagnose bottlenecks from telemetry and choose the smallest sufficient architecture change.

Problem
Scalability education often rewards naming powerful technologies instead of reading evidence, protecting invariants, and making proportionate trade-offs.
Design
Twelve progressive incidents; each asks for the smallest sufficient change against capacity signals and failure modes, not the most powerful one.
Status
Live at lab.ghassan-alhamoud.com · open source
Evidence
Playable incident scenarios with modeled outcomes; full reasoning documented in the repository.
Boundary
Outcomes are modeled, not measured against production traffic. The lab teaches decision discipline, not benchmark numbers.

Tamoz

In active development

A Ruby-native durable agent framework for checkpointed, interruptible, observable, and evaluation-governed AI workflows.

Problem
Agent frameworks often move quickly on demos while leaving durability, review boundaries, evaluation evidence, and failure recovery as afterthoughts.
Design
Deterministic graph execution with SQLite-backed checkpoints; evaluation gates are first-class controls, not post-hoc reports.
Status
In active development · core runtime protocols being published as independent gems
Evidence
Runtime protocols, deterministic graph execution, SQLite durability, a RubyLLM agent runtime, and an evaluation harness are visible in the public repository.
Boundary
Pre-1.0: APIs and the storage format are still evolving; not yet load-tested at production scale.

ALMS

Public release

A self-hosted MCP server that gives autonomous agents shared operational memory without turning into an orchestration framework.

Problem
Agent fleets repeatedly rediscover the same failure modes because useful learnings stay trapped inside individual runs.
Design
A narrow control plane — register, publish learnings, sync, pull protocols by tag — that agents can leave and rejoin; it stores knowledge and gets out of the way.
Status
Public release 0.1.0 · open source
Evidence
Agents can register, publish learnings, sync new knowledge, and pull operational protocols by tag while continuing to work if ALMS is offline.
Boundary
Single-operator, self-hosted scope. A known TTL-decay issue (documented in the release notes) requires compensating controls for repeated decay sweeps.

About

I am a Senior Software Engineer with more than 15 years of experience building backend systems and modernizing complex architectures. My work focuses on reducing coupling, establishing clear service boundaries, and improving the scalability and reliability of platforms.

At Vinted, I led the extraction of the platform's first independently operated microservice, using Kafka and a dedicated database. I also worked on parcel-tracking performance, carrier webhook integrations, crawler infrastructure, engineering practices, and technical hiring. Between Vinted and Wayfair, I worked at PlusDental on API migration, internal platform tools, testing practices, and architecture improvements. At Wayfair, I was Tech Lead for a database-decoupling project and built the MVP for a decoupled Kafka consumer.

Outside my professional roles, I build systems to explore these ideas in practice: ScaleShop, an interactive scalability lab; Tamoz, a stream-oriented agent project; and an AI-assisted film-production pipeline that produced two short films. I write about distributed systems, event-driven architecture, reliability, and practical AI-agent infrastructure.
